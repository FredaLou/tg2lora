"# LLM Dataset Generator\n\nA CLI pipeline for building personality/fine-tuning datasets from raw conversation data.\n\nFilter raw dialogues (Telegram exports, JSONL, conversation files) through rule-based and optional LLM-based quality checks, then generate assistant replies via a local LLM server (llama.cpp or any OpenAI-compatible endpoint).\n\n## Pipeline\n\n```\nraw input → [source parser] → [rule filter] → [LLM judge (optional)] → [LLM generation] → output dataset\n```\n\n## Supported Formats\n\n| Stage | Input | Output |\n|-------|-------|--------|\n| Filter | Telegram JSON, JSONL, conversations JSON | JSON array of strings |\n| Generate | JSON array of strings | conversations / chatml / alpaca |\n\n### Output Formats\n\n- **conversations** — `[{\"conversations\": [{\"from\": \"human\", \"value\": \"...\"}, {\"from\": \"gpt\", \"value\": \"...\"}]}]`\n- **chatml** — `<|user|>text<|assistant|>reply<|end|>` (one per line)\n- **alpaca** — `[{\"prompt\": \"...\", \"completion\": \"...\"}]`\n\n## Setup\n\n```bash\npip install -r requirements.txt\n```\n\nYou need a local LLM server running (llama.cpp, vLLM, or any OpenAI-compatible API):\n\n```bash\n# Example: llama.cpp\n./llama_cpp_bin/llama-server -m models/model.gguf -c 4096 --port 8000\n```\n\n## Usage\n\n### Full pipeline (filter + generate)\n\n```bash\npython main.py full --input data/my_chat.json --output data/train.json\n```\n\n### With intermediate filtered output\n\n```bash\npython main.py full --input data/my_chat.json --output data/train.json --filtered-output data/filtered.json\n```\n\n### Override output format\n\n```bash\npython main.py full --input data/my_chat.json --output data/train.json --format chatml\npython main.py full --input data/my_chat.json --output data/train.json --format alpaca\n```\n\n### Filter only\n\n```bash\npython main.py filter --input data/my_chat.json --output data/filtered.json\n```\n\n### Generate only (from pre-filtered texts)\n\n```bash\npython main.py generate --input data/filtered.json --output data/train.json\n```\n\n### Custom config\n\n```bash\npython main.py full --input data/chat.json --output data/train.json --config my_config.yaml\n```\n\n## Configuration\n\nAll settings live in `dataset_config.yaml`:\n\n```yaml\nsource:\n  format: telegram        # telegram | jsonl | conversations\n  field: user             # field name for user text\n\nfilters:\n  min_len: 30             # minimum text length\n  max_len: 300            # maximum text length\n  rule_threshold: 0       # minimum rule-based score\n  range:\n    start: 0              # start index (0 = all)\n    end: null             # end index (null = all)\n  llm_judge:\n    enabled: false        # enable LLM-based quality filtering\n    url: \"http://127.0.0.1:8001/completion\"\n    keep_score: 5         # minimum score to keep\n    max_results: 1000\n\ngeneration:\n  url: \"http://127.0.0.1:8000/completion\"\n  temperature: 0.85\n  max_tokens: 150\n  top_p: 0.9\n  min_p: 0.05\n  repeat_penalty: 1.1\n  delay: 0.2\n  stop: [\"</s>\", \"User:\"]\n  system_prompt: |\n    You are a helpful assistant.\n    Be natural, concise, and direct.\n\noutput:\n  format: conversations   # conversations | chatml | alpaca\n```\n\n## Project Structure\n\n```\n├── main.py              # CLI entry point\n├── dataset_config.yaml  # Main configuration\n├── config/\n│   └── loader.py        # Config loading & validation\n├── sources/\n│   ├── base.py          # Abstract source interface\n│   ├── telegram.py      # Telegram export parser\n│   ├── jsonl.py         # JSONL / JSON parser\n│   └── conversations.py # Conversation format parser\n├── filters/\n│   ├── rules.py         # Rule-based cleaning & scoring\n│   └── llm_judge.py     # LLM-based quality judge\n├── generators/\n│   └── llama_server.py  # LLM server client\n├── output/\n│   ├── conversations.py # Conversations format\n│   ├── chatml.py        # ChatML format\n│   └── alpaca.py        # Alpaca format\n└── data/                # Place input/output files here\n```\n\n## Notes\n\n- Generation supports **resume**: if the output file already exists, already-processed texts are skipped.\n- The LLM judge is **opt-in** via config (`llm_judge.enabled: true`).\n- Works with any OpenAI-compatible server (llama.cpp, vLLM, text-generation-webui, etc.).\n- Fully AI-assisted project.\n\n## License\n\nMIT\n```\n
